Guide d'execution - Gestion des Reservations de Salles



Les fichiers JAR sont deja generes et prets a l'emploi. La base de donnees SQLite (ReservationDB.db) est initialisee automatiquement, sans mot de passe.



1. Execution (respecter cet ordre)



Etape 1 : Lancer le serveur en premier (Terminal 1)

java -jar Serveur.jar


Etape 2 : Lancer le client en deuxieme (Terminal 2)

java -jar Client.jar



Pour tester plusieurs utilisateurs en meme temps, lancez java -jar Client.jar dans plusieurs terminaux.
